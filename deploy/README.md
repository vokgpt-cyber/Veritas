# VERITAS Deployment

Deployment entry points for VERITAS pilot releases.

- `it-ubuntu/` - VERITAS 1.0 server deployment for EPAM IT on Ubuntu + NVIDIA
  GPU. Start with `it-ubuntu/README.md`, use
  `it-ubuntu/OPERATIONS_CHECKLIST.md` for operations, and complete
  `it-ubuntu/SECURITY_REVIEW.md` before pilot exposure.

Windows workstation development and local Docker startup remain in the
repository root via `START_VERITAS_DOCKER.bat`.
