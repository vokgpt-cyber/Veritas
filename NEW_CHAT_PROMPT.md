## Что ещё передать на новый компьютер

Помимо самого репо, на новой машине должно быть:

1. **Python 3.11+** на PATH
2. **Node.js 20+** на PATH (для `npm`)
3. **Ollama** установлен и запущен (`ollama serve`). Подтянуть модель: `ollama pull gemma4:26b` (~16GB, один раз)
4. **ffmpeg** на PATH (или будем использовать torchaudio fallback)
5. **NVIDIA driver** с поддержкой CUDA 12.1+ если используется GPU
6. **`.env` файл** в корне репо с секретами:
   ```
   HF_TOKEN=<huggingface_read_token>
   EPAM_AUTH_SECRET_KEY=<long_random_secret>
   ANTHROPIC_API_KEY=<optional_cloud_key>
   ```

Что не нужно копировать (пересоздаётся автоматически):

- `venv/` → запустите `REBUILD_VENV.bat` (~20 минут один раз)
- `frontend/node_modules/` → `npm install` в папке frontend
- `models/` cache → скачается при первом запуске
- `data/meetings/<job_id>/` рабочие папки

## Первый запуск на новой машине

1. Скопировать репо
2. Создать `.env` с секретами (см. выше)
3. Установить Python, Node, Ollama, ffmpeg
4. `ollama pull gemma4:26b`
5. Двойной клик на `REBUILD_VENV.bat` (один раз, ~20 мин)
6. Двойной клик на `START_VERITAS_MVP.bat`
7. Открыть `localhost:3000` (или 3001/3002 если порт занят — bat найдёт сам)
8. Войти как `admin / admin`
